# v1.0.0 · Prototipo académico MLOps

Primera versión documentada del proyecto de scoring de riesgo crediticio sobre **datos bancarios completamente sintéticos**. Esta publicación es una **pre-release experimental**, no un sistema financiero de producción.

## Componentes incluidos

- Cuaderno de generación de 17 tablas sintéticas, escenarios de cohortes y variables anteriores a las solicitudes.
- Cuaderno de regresión logística L2, C = 0,1, con 18 características e interpretación del score ilustrativo de 300 a 850.
- API REST con FastAPI para inferencia, validación estricta de las 18 características y endpoints de salud.
- Imagen Docker y pruebas automáticas de API, notebooks y construcción del contenedor.
- Monitor exploratorio de cambios de distribución con PSI, valores faltantes y categorías nuevas, reportes agregados JSON/Markdown y demostración sintética en CI.
- Flujo Git-Flow documentado mediante las integraciones #1, #2, #3 y #4.

## Limitaciones y seguridad

- La aplicación **no es apta para aprobar o rechazar préstamos reales** ni reproduce políticas de BBVA.
- El modelo entrenado (`.joblib`) no se distribuye con esta versión. Para usar `/predict` se debe aportar un artefacto propio y confiable con las versiones de dependencias compatibles; de lo contrario devuelve HTTP 503.
- Las etiquetas de incumplimiento a 12 meses y la separación histórica implican una evaluación retrospectiva; no una simulación estricta de disponibilidad temporal de etiquetas.
- Muestras pequeñas (15 impagos en entrenamiento, 3 en validación, 11 en prueba), posible sesgo de selección y probabilidades no suficientemente validadas/calibradas.
- `tasa_nominal_anual_simulada` se conserva sin auditoría completa de posible circularidad.
- El monitor mide **data drift**, no degradación predictiva ni riesgos reales en línea; los avisos PSI son heurísticos.
- La API no incorpora autenticación, TLS ni salvaguardas requeridas para exposición pública.
